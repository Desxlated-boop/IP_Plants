# IP_Plants - Сервис учета домашних растений

## Назначение
Консольное приложение для ведения учета домашних растений, отслеживания графика полива и поиска растений по коллекции.

## Целевая аудитория
Любители комнатных растений, начинающие садоводы.

## Предметная область
Домашнее цветоводство. Учет микроклимата и графиков ухода за комнатными растениями.

## Основные сущности
- Растение (название, вид, частота полива, дата последнего полива).

## Реализованные функции (ПР2)
- Добавление нового растения в коллекцию.
- Поиск растений по названию.
- Автоматическая проверка растений, требующих полива на текущую дату.
- Сохранение и загрузка коллекции в JSON.
- Безопасный ввод данных с обработкой исключений.

## Структура проекта
- `main.py` – точка запуска, меню приложения.
- `plants.py` – функции обработки данных (поиск, фильтрация, добавление).
- `storage.py` – работа с файлами (JSON).
- `utils.py` – вспомогательные функции ввода.
- `data/plants.json` – хранилище данных.
- `tests/` – автоматизированные тесты.

## Требования и запуск
- Python 3.x
- Установка зависимостей: `pip install -r requirements.txt`
- Запуск программы: `python main.py`
- Запуск тестов: `pytest`
- Проверка кода: `flake8 .`
