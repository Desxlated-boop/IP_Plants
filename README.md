# IP_Plants

# Сервис учета домашних коллекций растений

## Назначение
Приложение помогает владельцам домашних растений отслеживать график полива, определять оптимальное местоположение для цветка и вести учет условий содержания.

## Целевая аудитория
Любители растений, начинающие садоводы, люди, которые часто забывают поливать свои цветы или не знают специфики ухода за ними.

## Предметная область
Домашнее цветоводство и ботаника. Учет микроклимата и графиков ухода за комнатными растениями.

## Основные сущности
- Растение (название, вид, частота полива, требования к свету).
- Владелец (пользователь, который ухаживает за растением).
- График полива (дата последнего полива, интервал).

## Основные функции
1. Проверка необходимости полива (на основе дней, прошедших с последнего полива).
2. Расчет дней, оставшихся до следующего полива.
3. Определение рекомендуемого местоположения (на основе требований к освещению).
4. Формирование сводной карточки информации о растении.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных для хранения коллекций;
- реализация регистрации и авторизации пользователей;
- разработка REST API;
- контейнеризация приложения в Docker;
- настройка CI/CD.
